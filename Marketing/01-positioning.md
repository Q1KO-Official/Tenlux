# Tenlux / 执光 产品定位

## 一句话介绍

Tenlux（执光）是一款专注于 Windows 深浅模式切换体验的轻量级托盘工具：切换更快，自动化更顺，后台占用更克制。

## 核心卖点

1. 真正托盘化：不打扰桌面，设置窗不常驻，平时像一个安静的系统能力。
2. 切换完整：不只切系统主题，还能联动壁纸、快捷键、定时、通知。
3. 背景轻量：设置窗口未打开时尽量不保留多余 UI 与图片资源。
4. 上手直接：第一次打开就能理解，之后基本只需要托盘图标。

## 目标用户

- 经常在白天 / 夜晚切换 Windows 主题的人
- 桌面美化用户
- 想让深浅模式和壁纸一起切换的人
- 不喜欢大型“系统增强工具箱”，只想要一个专注小工具的人

## 产品气质

- 安静
- 克制
- 可靠
- 有审美，但不浮夸

## 推荐宣传句

- 把 Windows 的光与暗，交还给你。
- 真正轻量的 Windows 深浅模式切换工具。
- 不常打开，却每天都会用到。
- 托盘里最安静的那盏灯。

## 与同类产品的差异化表达

- 不是“大而全”的系统工具，而是“专而精”的主题切换器
- 不是只切一个注册表开关，而是把主题、壁纸、热键、定时打通
- 不是开着设置窗常驻内存，而是把后台状态尽量做轻
