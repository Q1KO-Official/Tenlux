# Tenlux / 执光 营销资产索引

这个目录是 Tenlux 当前版本的对外传播资料包。

## 文件说明

- `01-positioning.md`
  产品定位、核心卖点、目标用户、宣传口径。
- `02-launch-plan.md`
  发布节奏、素材清单、评论区引导和后续内容方向。
- `03-bilibili.md`
  B 站视频标题、简介、脚本和标签建议。
- `04-douyin.md`
  抖音短视频脚本、口播和画面顺序。
- `05-xiaohongshu.md`
  小红书图文文案、封面文案和配图建议。
- `06-xiaoheihe.md`
  小黑盒帖子文案和评论区引导。
- `07-press-kit.md`
  媒体素材包说明、短简介和关键词。
- `08-release-notes.md`
  适合发版本动态、更新日志和社区公告的文案。
- `09-platform-fit.md`
  为什么不同平台要用不同打法，以及每个平台更适合强调什么。
- `10-comment-replies.md`
  评论区和私信高频问题回复模板。
- `11-content-calendar.md`
  两周内容发布节奏安排。
- `12-faq.md`
  面向用户和评论区的常见问题说明。
- `13-launch-checklist.md`
  正式发布前的产品、视觉、素材、网页检查项。
- `14-shotlist.md`
  录屏和截图素材拍摄清单。
- `15-release-package.md`
  如何把宣传资产和项目说明打成一份对外发布包。
- `16-release-bundle.md`
  如何导出真正给用户分发的软件发布产物。

## 推荐使用顺序

1. 先看 `01-positioning.md`
2. 再看 `02-launch-plan.md`
3. 按平台选择对应文案
4. 发帖前从 `07-press-kit.md` 提取短简介和关键词
5. 发版本时使用 `08-release-notes.md`
6. 根据 `09-platform-fit.md` 调整平台侧表达
7. 用 `10-comment-replies.md` 和 `11-content-calendar.md` 做持续运营
8. 发版前走一遍 `13-launch-checklist.md`
9. 录屏和配图按 `14-shotlist.md` 补齐
10. 对外发送前用 `15-release-package.md` 和导出脚本整理发布包
11. 真正分发应用时走 `16-release-bundle.md`
