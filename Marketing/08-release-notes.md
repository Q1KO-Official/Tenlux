# Tenlux / 执光 版本更新文案

## 长版更新说明

Tenlux 这次更新，核心在两个方向：

1. 更像一个长期驻留在托盘里的系统工具
2. 更像一个真正可持续迭代的产品

这次我们重点优化了设置窗口未打开时和设置关闭后的后台状态，尽量释放不再需要的页面、图片和缓存资源，让它回到更轻的后台形态。

同时，产品层也把首页、壁纸预设和常规设置重新收束了一遍：

- 更清晰的首页和壁纸预览区
- 更轻的常规设置入口
- 更完整的对外宣传与发布资料

Tenlux 依然保持原来的方向：
专注于 Windows 深浅模式切换，不做臃肿工具箱，而是把主题、壁纸、热键和定时这件事做到足够顺手。

## 短版更新说明

本次更新重点：

- 优化设置窗口关闭后的资源释放
- 优化未打开设置时的后台占用逻辑
- 调整首页和壁纸页的产品观感
- 收束常规设置，减少杂项入口
- 补齐宣传站和平台发布文案

## 社区动态版

Tenlux 新一版继续围绕“轻量”和“长期使用体验”在打磨。

这次不是单纯加功能，而是把后台状态和资源释放继续往前推了一步。你平时不打开设置的时候，它就应该更像一个安静的系统补完，而不是一个还挂着整套界面的软件。

另外，我们也补上了整套对外展示内容，方便后续持续更新和传播。

## 一句话更新摘要

- 更轻的后台，更完整的切换体验。
- 把 Windows 的光与暗，再往前打磨了一版。
