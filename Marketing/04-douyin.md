# 抖音短视频脚本

## 方向一：快节奏功能演示

### 标题

Windows 深浅模式，这样切才顺手

### 口播脚本

你是不是也会反复切 Windows 深色和浅色模式？

我做了个小工具，平时缩在托盘里，点一下就切主题。
还能自动换壁纸、设全局热键、按时间自动切。

重点是，它不是那种功能堆很满、后台也很重的工具。
不打开设置的时候，它就尽量安静待着。

名字叫 Tenlux，中文叫执光。

### 画面顺序

1. 托盘图标切换
2. 深浅模式瞬间变化
3. 壁纸联动变化
4. 设置页快速扫过
5. 回到托盘收尾

### 屏幕字幕短句

- 点一下，切主题
- 深浅壁纸自动联动
- 全局热键随时切
- 定时自动切换
- 平时安静待在托盘

## 方向二：开发者故事向

### 标题

我为什么重新做了一个 Windows 深浅模式工具

### 口播脚本

原生深浅模式不是不能用。
只是每次用的时候，我都觉得差一点。

差在托盘交互，差在自动化，差在壁纸联动，
也差在很多工具平时根本不用，却还在后台挂着整套设置界面。

所以我做了 Tenlux。
一个更像系统能力，而不是像“大工具箱”的小软件。
