## 关于 Tenlux

Tenlux（执光）是一款轻量级 Windows 工具，专注于系统深色/浅色模式的无缝切换。不同于 Windows 原生的"非黑即白"，Tenlux 允许你精细控制主题、壁纸、光标等视觉元素的联动方式，打造真正个性化的桌面体验。

## 核心特性

| 功能 | 说明 |
|------|------|
| 一键主题切换 | 在深色与浅色模式之间即时切换，无需重启 |
| 壁纸联动 | 根据当前主题自动切换桌面壁纸 |
| 光标主题同步 | 切换模式时同步更改鼠标光标样式 |
| 任务栏风格 | 任务栏颜色与主题保持一致 |
| 自定义调度 | 支持定时自动切换或手动触发 |
| 轻量无侵入 | 不修改系统文件，卸载即走 |
