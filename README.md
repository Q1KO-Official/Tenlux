
# ToggleDarkMode

一个“快速切换 Windows 深色/浅色模式”的轻量托盘工具。

## 我为什么开发这个工具

Windows 原生切换深浅色模式的路径比较长，通常需要：

`打开设置 -> 个性化 -> 颜色 -> 选择模式 -> 深色/浅色 -> 关闭设置`

这个流程在日常使用中很频繁，但步骤多、效率低。  
所以我开发了 `ToggleDarkMode`：常驻系统托盘后，只需单击或双击任务栏通知区图标，就能一键切换系统深浅色模式。

## 核心功能

- 一键切换深色/浅色模式（支持单击或双击触发）
- 托盘右键菜单快速控制
- 遮罩动画可开关
- 遮罩持续时间可调（多档位）
- 开机自动启动可选（安装时可选；程序菜单内也可随时开关）
- 多语言菜单（English / 简体中文 / 繁體中文）
- 单实例运行（避免重复启动多个托盘图标）

## 下载与安装

1. 下载 [`ToggleDarkMode_1.0_x86.exe`](dist/ToggleDarkMode_1.0_x86.exe)
2. 双击运行安装程序
3. 按安装向导完成安装
4. 安装完成后可立即启动

## 使用方式

1. 启动后程序会显示在系统托盘（任务栏右下角通知区）
2. 按你设置的触发方式（单击/双击）切换深浅色
3. 右键托盘图标可打开菜单，调整：
- 触发方式（单击切换 / 双击切换）
- 遮罩开关
- 遮罩持续时间
- 语言
- 开机自动启动

## 兼容性与运行要求

### 架构兼容性

- 兼容 x64 和 x86（64 位/32 位）Windows 系统

- `Windows 10 1809+`：完全支持
- `Windows 11 全部版本`：完全支持
- `Windows 10 1803 及更早`：程序可运行，但由于相关注册表项缺失，深色主题切换可能不生效

适配范围：**所有 Windows 10 1809+ 与全部 Windows 11，零额外依赖。**

## 配置文件位置

- 配置文件保存在用户文档目录：  
  `文档\ToggleDarkMode\ToggleDarkMode.cfg`

说明：

- 配置与安装目录解耦，避免安装在 `Program Files` 时遇到写权限问题
- 卸载程序不会强制删除该配置文件，便于保留你的个人设置

## 已知说明

- 如果切换后视觉效果延迟，通常是系统主题刷新速度导致，属于 Windows 行为
- 若你手动禁用了相关主题项或使用第三方主题工具，可能影响切换效果
